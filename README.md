## Quickstart

```powershell
# 1. Clone and enter the backend
cd MOGGERS_V2-main\backend

# 2. Install dependencies (requires Python 3.11+, uv recommended)
pip install -e ".[dev]"          # or: uv sync

# 3. Copy environment template and fill in keys
copy .env.example .env

# 4. Run the API server
uvicorn app.main:app --reload --port 8000

# 5. Run tests
python -m pytest tests/ -v --tb=short -p no:warnings

# 6. Generate replay scenario (seed 7)
New-Item -ItemType Directory -Force -Path replay
python -m scenario.generate --seed 7 --output replay/scenario_v1.jsonl

# 7. Run eval suite
python -m eval.run_all
# results -> eval/reports/summary.json
```

## Pre-trained Models Used

No model training is required. All models are used inference-only:

| Task | Model |
|------|-------|
| Sentiment (multilingual) | `cardiffnlp/twitter-xlm-roberta-base-sentiment` |
| Multi-emotion (anxiety / excitement / anger / joy / fear / disgust / neutral) | `j-hartmann/emotion-english-distilroberta-base` |
| Language identification | `papluca/xlm-roberta-base-language-detection` |
| Sentence embeddings (multilingual) | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` |
| Image-text CLIP | `openai/clip-vit-base-patch32` |
| Sarcasm detection | `helinivan/english-sarcasm-detector` |
| Zero-shot topic / demographic NLI | `facebook/bart-large-mnli` and `MoritzLaurer/mDeBERTa-v3-base-mnli-xnli` |

## Honest Limitations

1. **Live collectors require secrets** — X (twscrape), Telegram (Telethon), Reddit (PRAW), YouTube Data API keys must be supplied by the operator in `.env`. No keys are bundled.
2. **NLP models are CPU-slow** — Emotion and embedding pipelines use HuggingFace Inference API by default. Local GPU inference is supported but not auto-configured.
3. **Graph store is in-memory** — The NetworkX graph is rebuilt from SQLite on each restart. A production swap to Neo4j or Amazon Neptune requires only a config change (interface is implemented).
4. **FAISS index is on-disk flat** — Suitable for <= 5 M vectors. Switch to IVF/HNSW for larger datasets.
5. **Scenario data is entirely synthetic** — `replay/scenario_v1.jsonl` posts are labelled `synthetic=true` and must not be presented as real intelligence.
6. **OpenTimestamps proofs are stubbed** — `app/ledger/ots.py` returns a placeholder until a Bitcoin node or OTS calendar is reachable.
7. **k-anonymity is enforced at K=10** — Buckets with fewer than 10 accounts are suppressed; this may hide genuine regional signals in low-volume datasets.
