# Data sources and models

## Datasets
| Data | Source | License / status |
|---|---|---|
| Demo scenario (`replay/scenario_v1.jsonl`, `truth.json`) | Generated by `backend/scenario/generate.py` (seed 7; held-out eval seed 11) | Synthetic, team-authored; fictional places/accounts/events |
| Scenario images (`data/media/dam_*.png/jpg`) | Drawn by the generator (Pillow) | Synthetic |
| pHash transformation suite | 200 images generated in `eval/phash_suite.py` | Synthetic |
| Gazetteer (`data/gazetteer/india.json`) | States/UTs and major cities of India, compiled by the team | Public facts |
| Lexicons (`data/lexicons/*`) | Compiled by the team (English and romanised Hindi cue words) | Team-authored |
| Collector fixtures (`backend/tests/fixtures/`) | Built from documented library field names | Team-authored; not real traffic |

Not used yet: SentiMix, HASOC, GoEmotions, IndicXTREME (PRD 11.1). Verify licences
before using them for the planned MuRIL fine-tune.

| Emotion | j-hartmann/emotion-english-distilroberta-base | check model card |

Download: `python scripts/fetch_models.py` (writes to `models/`, gitignored).
